Temat: Protokoły pocztowe

Cel i zakres

Celem ćwiczenia było poznanie protokołów pocztowych SMTP, POP3 i IMAP, ręczne wysłanie wiadomości przez SMTP, konfiguracja klienta poczty, analiza nagłówków i załączników oraz test wysyłki z PHP.

Badanie protokołu SMTP

Po zalogowaniu na serwer mts.wibro.agh.edu.pl połączono się z lokalnym serwerem SMTP poleceniem telnet localhost 25.

MAIL FROM:<sNr_Indeksu@mts.wibro.agh.edu.pl>

Do kolegi/koleżanki wysłano wiadomości z różnymi typami załączników: plik graficzny, multimedialny i tekstowy ASCII.

Typ załącznikaRozmiar pliku natywnegoRozmiar wiadomościZmiana

Analiza nagłówków pokazała m.in. pola From, To, Subject, Date, Message-ID, Received oraz Content-Type. Przy załącznikach pojawiają się granice MIME i informacja o kodowaniu, najczęściej base64.

Wysyłanie poczty z PHP i wnioski

Przetestowano skrypty PHP wysyłające wiadomość tekstową i HTML. W nagłówkach należy wskazać nadawcę, adres odpowiedzi i typ treści z kodowaniem UTF-8.

<?php
$msg = "Dzień dobry, wiadomość testowa.";
$to = "sNrIndeksu@mts.wibro.agh.edu.pl";
$subject = "Mój pierwszy mail";
$headers = "From: moja strona <sNrIndeksu>
";
$headers .= "Reply-To: sNrIndeksu@mts.wibro.agh.edu.pl
";
$headers .= "Content-Type: text/plain; charset=UTF-8
";
if (mail($to, $subject, $msg, $headers)) {
    echo "Wysłano e-mail";
} else {
    echo "Nie wysłano e-maila";
}
?>

Wniosek: SMTP odpowiada za przekazywanie wiadomości, a POP3 i IMAP za dostęp do skrzynki. Nagłówki i MIME opisują trasę, treść oraz załączniki wiadomości.
