Statyka

ΣFx=0, ΣFy=0, ΣMO=0  (układ płaski)
ΣFx=ΣFy=ΣFz=0 oraz ΣMx=ΣMy=ΣMz=0 (3D)
MO = r × P, |MO| = P·d
Wg = ΣPi, Mg = Σ(ri×Pi)+ΣMpar

Tarcie

T ≤ μsN
T = μN na granicy poślizgu
μ = tgρ
S2/S1 = e^(μα)
klin samohamowny: tgα ≤ μ

Kinematyka punktu

r = r(t)
v = dr/dt
a = dv/dt = d²r/dt²
a = aτ + an
aτ = dv/dt, an = v²/ρ
s = rφ, v = rω, an = rω², aτ = rε

Ruch okresowy i złożony

x = A sin(ωt+γ)
T = 2π/ω, f = 1/T
v = ωA cos(ωt+γ)
a = -ω²x
vb = vu + vw
ab = au + aw + 2ω×vw

Bryła sztywna

ruch postępowy: vA=vB, aA=aB
ruch obrotowy: v=ω×r
ruch płaski/dowolny:
vA = vO + ω×rOA
aA = aO + ε×rOA + ω×(ω×rOA)
toczenie: vśr = Rω

Dynamika

ΣP = ma
mx¨=ΣPx, my¨=ΣPy, mz¨=ΣPz
B = -ma
ΣP + B = 0
G = mg
Fs = -kx
J = ∫r²dm, Steiner: J = Js + Md²
