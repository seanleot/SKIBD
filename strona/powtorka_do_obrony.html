POWTÓRKA DO OBRONY STRONY WWW

1. Krótkie przedstawienie projektu

„Moja strona jest prostym portalem wykonanym w HTML, CSS i PHP. Strona główna zawiera menu, odnośniki do sprawozdań, grafiki, formularz i stopkę. Dodatkowe podstrony realizują kalkulator, losowanie w PHP oraz obsługę bazy danych MySQL. Strona jest umieszczona w katalogu public_html na serwerze zajęciowym i działa przez serwer WWW.”

2. Najważniejsze pliki

  • index.html – strona główna.
  • style.css – wygląd wszystkich stron.
  • raport1.html–raport9.html – sprawozdania.
  • kalkulator.php – obliczenia po stronie serwera.
  • losowanie.php – zadanie z laboratorium 8.
  • baza.php – formularz i baza MySQL.
  • favicon.png – ikona karty.
  • img/ – grafiki.
  • lyricpost/ – osobna podstrona/aplikacja.

Dlaczego `index.html`?

Serwer WWW domyślnie szuka pliku index.html lub index.php, gdy użytkownik podaje adres katalogu bez nazwy pliku.

3. HTML

Czym jest HTML?

Opisuje strukturę i zawartość strony: nagłówki, tekst, obrazy, formularze, tabele i linki.

Co robi `<!DOCTYPE html>`?

Informuje przeglądarkę, że dokument korzysta z HTML5.

Po co jest `<head>`?

Zawiera kodowanie, tytuł karty, podłączenie CSS, favicon i ustawienia responsywności.

Po co UTF-8?

<meta charset="UTF-8"> zapewnia poprawne wyświetlanie polskich znaków.

`id` a `class`

  • id jest unikalne i może być celem linku, np. #stopka.
  • class może być użyta przez wiele elementów i służy do wspólnego stylowania.

Jak działa link?

<a href="raport1.html">Raport 1</a> otwiera wskazany plik.

Ścieżka względna i bezwzględna

  • względna: img/kot.jpg,
  • bezwzględna: pełny adres https://....

Link do sekcji

<a href="#stopka">Na dół</a> przewija do elementu z id="stopka".

Po co `alt`?

Opisuje obraz, gdy grafika się nie załaduje, i poprawia dostępność.

Dlaczego wielkość liter jest ważna?

Linux rozróżnia Kot.jpg i kot.jpg.

4. CSS

Czym jest CSS?

Odpowiada za kolory, układ, odstępy, rozmiary i responsywność.

Dlaczego osobny `style.css`?

Oddziela treść od wyglądu, zmniejsza powtarzanie kodu i pozwala zmienić styl wszystkich stron w jednym miejscu.

Dlaczego spokojny pomarańczowy?

To jednolity motyw wizualny. Elementy interaktywne są widoczne, ale kolor nie jest krzykliwy.

Jak działa sidebar?

Zwykle ma position: fixed, więc pozostaje widoczny. Treść ma margin-left, żeby nie wejść pod menu.

Co robi `display: grid`?

Tworzy układ wierszy i kolumn, np. kafelki raportów i galerię.

Co oznacza responsywność?

Strona dopasowuje się do szerokości ekranu. Pomagają max-width, grid/flex, @media i viewport.

Co robi `!important`?

Wymusza pierwszeństwo reguły CSS. Należy używać go oszczędnie.

5. Formularze

Formularz pobiera dane od użytkownika.

Najważniejsze:

  • action – dokąd wysłać dane,
  • method – jak je wysłać,
  • name – nazwa pola dla PHP,
  • submit – przycisk wysyłający.

GET a POST

  • GET umieszcza dane w URL i nadaje się do odczytu, wyszukiwania i filtrów.
  • POST przesyła dane w treści żądania i nadaje się do dodawania, usuwania i zmiany danych.

POST nie szyfruje danych. Szyfrowanie zapewnia HTTPS.

Po co `name`?

PHP odczytuje wartość przez $_POST["nazwa_pola"].

Pole hidden

Jest niewidoczne, ale wysyła wartość, np. identyfikator rekordu do usunięcia.

6. PHP

Czym jest PHP?

Język wykonywany po stronie serwera. Serwer wykonuje kod i wysyła przeglądarce gotowy HTML.

Dlaczego rozszerzenie `.php`?

Serwer rozpoznaje wtedy, że plik ma zostać wykonany przez PHP.

Dlaczego PHP nie działa po dwukliku?

Otwarcie lokalne omija serwer. Plik trzeba otworzyć przez adres HTTP serwera.

`echo`

Wyświetla tekst lub HTML.

`if`

Wykonuje kod po spełnieniu warunku.

`switch`

Wybiera jeden z kilku wariantów.

`for`

Powtarza kod określoną liczbę razy.

`isset()`

Sprawdza, czy zmienna lub pole formularza istnieje.

`$_POST`

Tablica zawierająca dane z formularza wysłanego metodą POST.

Dlaczego PHP jest przed HTML-em?

header("Location: ...") musi wykonać się przed wysłaniem treści HTML.

7. Kalkulator

Logika:

1. Użytkownik podaje dwie liczby.

2. Wybiera działanie.

3. Formularz wysyła dane przez POST.

4. PHP odczytuje dane.

5. switch lub if wybiera obliczenie.

6. Wynik jest wyświetlany.

Dlaczego sprawdzamy dzielenie przez zero?

Dzielenie przez zero jest niedozwolone, więc program pokazuje komunikat.

Dlaczego PHP?

HTML nie wykonuje obliczeń. PHP przetwarza dane po stronie serwera.

8. Losowanie z laboratorium 8

Logika:

1. Losowana jest liczba powtórzeń pętli.

2. W każdej iteracji losowane są A i B z zakresu 1–3.

3. Losowane jest 0 albo 1:

  • 0: A + B,
  • 1: A * B.

4. Wynik mieści się w zakresie 1–9.

5. Wynik wskazuje literę w dziewięcioliterowym wyrazie, np. KOMPUTERY.

6. Do litery przypisany jest komunikat.

7. Wyniki są pokazane:

  • bezpośrednio w pętli,
  • po zgromadzeniu ich w zmiennej i użyciu echo.

Jaki jest sens?

Ćwiczenie łączy losowanie, pętle, warunki, działania matematyczne, tekst i generowanie HTML przez PHP.

Dlaczego 9 liter?

Największy wynik to 3 * 3 = 9.

9. MySQL i baza danych

Czym jest baza?

Uporządkowany zbiór danych przechowywany w tabelach.

Tabela, kolumna, rekord

  • tabela – zbiór danych,
  • kolumna – typ informacji,
  • rekord – jeden wiersz, np. jedna osoba.

Po co `id`?

Jednoznacznie identyfikuje rekord.

`PRIMARY KEY`

Oznacza unikalny klucz główny.

`AUTO_INCREMENT`

Automatycznie nadaje kolejne id.

Podstawowe SQL

  • CREATE TABLE – tworzy tabelę,
  • INSERT – dodaje rekord,
  • SELECT – pobiera dane,
  • UPDATE – zmienia dane,
  • DELETE – usuwa rekord,
  • TRUNCATE – usuwa wszystkie rekordy i resetuje numerację,
  • DROP TABLE – usuwa tabelę.

Przepływ w `baza.php`

1. Formularz wysyła POST.

2. PHP łączy się z MySQL.

3. PHP wykonuje INSERT.

4. Następuje przekierowanie.

5. PHP wykonuje SELECT.

6. Dane są pokazane w tabeli HTML.

Jak działa usuwanie?

Przycisk przesyła ukryte usun_id. PHP wykonuje DELETE ... WHERE id = ....

Dlaczego odświeżenie dodawało duplikat?

Przeglądarka ponawiała ostatni POST, więc INSERT wykonywał się drugi raz.

Jak to naprawiono?

Schemat POST–Redirect–GET:

1. POST dodaje rekord.

2. PHP wykonuje header("Location: baza.php").

3. Przeglądarka przechodzi metodą GET.

4. Odświeżenie nie powtarza INSERT.

Najważniejsze funkcje mysqli

  • mysqli_connect() – połączenie,
  • mysqli_set_charset() – kodowanie,
  • mysqli_select_db() – wybór bazy,
  • mysqli_query() – wykonanie SQL,
  • mysqli_fetch_array() – pobieranie rekordów,
  • mysqli_close() – zamknięcie połączenia.

Bezpieczeństwo

W prawdziwej aplikacji należy użyć:

  • prepared statements,
  • walidacji,
  • htmlspecialchars(),
  • hasła do bazy poza katalogiem publicznym.

SQL Injection

Próba wstrzyknięcia kodu SQL przez formularz. Chronią prepared statements i walidacja.

10. Serwer

Po co `public_html`?

Serwer WWW udostępnia pliki użytkownika z tego katalogu.

Droga żądania

Przeglądarka → serwer WWW → HTML/PHP → ewentualnie MySQL → wynik HTML → przeglądarka.

SSH a HTTP

  • SSH służy do bezpiecznej pracy na serwerze.
  • HTTP/HTTPS służy do pobierania stron.

Dlaczego SSH zamiast Telnetu?

SSH szyfruje transmisję, login i hasło.

Po co prawa dostępu?

Serwer WWW musi móc wejść do katalogu i odczytać pliki.

11. HTTP

URL

Przykład:

http://mts.wibro.agh.edu.pl/~login/baza.php

  • http – protokół,
  • host – adres serwera,
  • ścieżka – położenie pliku.

HTTP jest bezstanowy

Każde żądanie jest niezależne. Stan utrzymuje się przez sesje, cookie lub bazę.

HTTP a HTTPS

HTTPS to HTTP przez szyfrowane TLS.

Cookie

Małe dane zapisane przez przeglądarkę, np. do logowania lub ustawień.

12. Favicon i grafiki

Favicon

<link rel="icon" type="image/png" href="favicon.png">

Dlaczego nowej ikony lub CSS czasem nie widać?

Przeglądarka korzysta z cache. Pomaga Ctrl + F5.

Dlaczego grafika nie działa?

Najczęściej:

  • zła ścieżka,
  • zła nazwa,
  • inna wielkość liter,
  • brak pliku,
  • brak prawa odczytu.

14. Prawdopodobne pytania prowadzącego

Dlaczego HTML i CSS osobno?

Aby oddzielić treść od wyglądu i nie powtarzać stylów.

Dlaczego PHP?

Kalkulator, losowanie i baza wymagają logiki po stronie serwera.

Po co baza?

Dane są trwałe i pozostają po zamknięciu przeglądarki.

Dlaczego usuwanie po `id`?

Bo id jednoznacznie wskazuje rekord.

Dlaczego POST do dodawania i usuwania?

Bo te operacje zmieniają stan bazy.

Dlaczego przekierowanie po INSERT?

Aby odświeżenie nie tworzyło duplikatu.

Dlaczego PHP przed HTML?

Aby obsłużyć formularz i nagłówek Location przed wysłaniem treści.

Dlaczego `#id` w menu?

Umożliwia przewijanie do sekcji bez ładowania nowej strony.

Dlaczego UTF-8?

Dla poprawnych polskich znaków w HTML, PHP i bazie.

Co dzieje się po kliknięciu „Dodaj”?

POST → PHP → INSERT → przekierowanie → SELECT → tabela HTML.

Co dzieje się po kliknięciu „Usuń”?

POST z id → DELETE → przekierowanie → aktualna lista.

Czy formularz jest bezpieczny?

W wersji laboratoryjnej działa, ale produkcyjnie potrzebne są prepared statements, walidacja i filtrowanie.
